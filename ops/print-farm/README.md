# Tri Star Print Farm Tracker

This directory preserves Steve's local Resonance print-farm work product.

- `tri-star-print-farm-tracker.xlsx` is the local workbook snapshot created before the
  tracker was imported into Google Sheets.
- `previews/` contains rendered views of the workbook tabs.
- `archive/build_tristar_print_farm_initial.mjs` is the original generator retained for
  provenance. It represents the initial workbook, not the later edits made in the live
  Google Sheet.

The live Google Sheet is the operational tracker. Later changes described in `LOG.md`,
including the Part File rollup and revised material units, may not be present in this local
snapshot.
