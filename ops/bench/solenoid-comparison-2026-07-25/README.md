# Solenoid Comparison - 2026-07-25

Editable bench-summary work product from Steve's DC power and solenoid testing.

- `solenoid-comparison.xlsx` compares the HS-0730B, HS-0530B, and X003801GWR units.
- `solenoid-comparison-preview.png` is a rendered view for quick review.
- `build-solenoid-comparison.mjs` regenerates the workbook and preview with the bundled
  spreadsheet artifact tooling.

Cells marked not tested or without a final result are deliberately left as such. The
architectural noisemaker decision remains ADR 0030; this sheet is supporting bench context.
